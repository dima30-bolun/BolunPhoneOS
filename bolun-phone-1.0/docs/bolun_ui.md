# Bolun UI design system

Bolun UI uses a dark-first visual language with large typography, clear lists, compact command bars, live tiles, quick settings, notification center, lock screen, multitasking cards, and smooth low-cost animations for 2012-2014 class hardware.

## Components

- Home: adaptive tile grid with accent color, text-first hierarchy, and live counters.
- Phone: large dial pad, call history, contact lookup, and one-hand command bar.
- Messages: conversation list, unread badges, threaded chat, attachment and voice entry affordances.
- Contacts: alphabetical jump rail, favorites, groups, and search.
- Music: collection pivots for artists, albums, songs, playlists, and now-playing controls.
- Settings: searchable grouped panels with quick toggles and device status.

All artwork must be original Bolun assets. Icons are described as vector primitives in the SDK asset pipeline rather than copied from another interface.
